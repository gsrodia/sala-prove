# Sala Prove

Web app per suonare insieme sulle basi: accende e spegne le tracce di ogni strumento di un brano, con un attacco di click prima di partire. Funziona offline una volta aggiunta alla schermata Home.

I brani (file `.basi`) restano sul telefono di chi li usa: questo repository contiene solo il codice dell'app.
